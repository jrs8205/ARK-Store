ARK-Store は、アプリとその更新を GitHub のリリースから直接届けます。デベロッパーは、オープンソースの公開リポジトリにトピック「arkstore」を追加するだけでアプリを公開できます。ストアには、最新のリリースに APK が添付されたこうしたリポジトリがすべて掲載され、どのアプリがインストール済みで、どのアプリに新しいバージョンがあるかがひと目でわかります。ファイルはワンタップでダウンロードでき、ご自身でインストールします。Root 化したデバイスでは、ストアがアプリのインストールと更新を行います。

• 自動で更新されるカタログ：APK を添付したリリースが公開されると、新しいアプリがすぐに掲載されます
• GitHub のアカウントやリポジトリを手動で追加することも可能
• GitHub のスター数とダウンロード数を表示
• 検索とカテゴリ
• 掲載されるのはオープンソースの公開アプリのみ
• APK 自体から読み取る正確なバージョン情報
• アプリと更新をワンタップでダウンロード、「すべてダウンロード」にも対応。Root ならインストール・更新も
• バックグラウンドで更新を確認して通知
• インストール済みのアプリが別の署名鍵で署名されている場合に警告
• アカウント不要・ログイン不要・サードパーティのサービス不使用
• 17 言語に対応
