ARK-Store trae aplicaciones y sus actualizaciones directamente desde sus versiones publicadas en GitHub. Los desarrolladores publican una aplicación añadiendo el tema "arkstore" a su repositorio público de código abierto. La tienda muestra todos los repositorios de este tipo cuya última versión publicada lleve un APK adjunto, indica qué aplicaciones están instaladas y cuáles tienen una versión más reciente, y descarga el archivo con un solo toque para que lo instales. En un dispositivo con root, las instala y actualiza por sí misma.

• Catálogo automático: una aplicación nueva aparece en cuanto se publica una versión con un APK
• También puedes añadir a mano una cuenta o un repositorio de GitHub
• Estrellas y número de descargas de GitHub
• Búsqueda y categorías
• Solo se incluyen aplicaciones públicas de código abierto
• Versiones exactas leídas del propio APK
• Descarga de aplicaciones y actualizaciones con un toque, con "Descargar todo", o instalación y actualización con root
• Comprobación de actualizaciones en segundo plano con notificación
• Avisa cuando una aplicación instalada está firmada con otra clave
• Sin cuentas, sin inicio de sesión y sin servicios de terceros
• Disponible en 17 idiomas
