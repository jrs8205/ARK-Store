ARK-Store 直接从 GitHub 发行版安装和更新应用。开发者只需为自己的开源公开仓库添加“arkstore”主题，即可发布应用。商店会列出所有最新发行版附有 APK 的此类仓库，显示哪些应用已安装、哪些有新版本，并可一键安装或更新。

• 自动收录：应用一发布附有 APK 的发行版，就会立即出现
• 也可以手动添加 GitHub 帐号或仓库
• 显示来自 GitHub 的星标数和下载次数
• 搜索和类别
• 只列出公开的开源应用
• 从 APK 本身读取准确的版本号
• 一键安装和更新，并支持“全部更新”
• 后台检查更新并发送通知
• 已安装的应用使用不同的签名密钥时会发出警告
• 无需帐号，无需登录，不使用第三方服务
• 支持 17 种语言
