ARK-Store는 GitHub 릴리스에서 앱과 업데이트를 바로 가져옵니다. 개발자는 공개 오픈소스 저장소에 "arkstore" 토픽을 추가하기만 하면 앱을 게시할 수 있습니다. 스토어는 최신 릴리스에 APK가 첨부된 이런 저장소를 모두 보여 주고, 어떤 앱이 설치되어 있고 어떤 앱에 새 버전이 있는지 표시하며, 탭 한 번으로 파일을 다운로드해 직접 설치할 수 있게 합니다. 루팅된 기기에서는 앱을 직접 설치하고 업데이트합니다.

• 자동 카탈로그: APK가 첨부된 릴리스가 게시되면 새 앱이 바로 표시됨
• GitHub 계정이나 저장소를 직접 추가할 수도 있음
• GitHub의 별 수와 다운로드 수
• 검색 및 카테고리
• 공개 오픈소스 앱만 표시
• APK에서 직접 읽어 오는 정확한 버전 정보
• 탭 한 번으로 앱과 업데이트 다운로드, "모두 다운로드" 지원, 루트로 설치 및 업데이트
• 백그라운드 업데이트 확인 및 알림
• 설치된 앱이 다른 키로 서명된 경우 경고
• 계정, 로그인, 서드 파티 서비스 없음
• 17개 언어 지원
